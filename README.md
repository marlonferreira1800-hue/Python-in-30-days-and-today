# Python em 30 dias — pratique hoje

Trilha interativa em português com 30 etapas, exemplos curtos e desafios diários.

## Como abrir

Abra o arquivo index.html no navegador. Não há dependências nem servidor obrigatório.

## Recursos

- 30 aulas, dos primeiros comandos a um pequeno projeto;
- busca por tema e navegação entre aulas;
- conclusão de aulas e barra de progresso;
- progresso salvo localmente no navegador;
- layout adaptado para computador e celular.

O progresso fica neste dispositivo, usando o armazenamento local do navegador.
